<summary><strong>What changed in this PR</strong></summary>

Fixes the beA “unread messages” indicator so it reflects the total across all configured postboxes (instead of only the last-checked one), and avoids overwriting the indicator when the total cannot be determined.

**Changes:**
- Sum unread counts across all postboxes in `BeaCheckTimerTask`.
- Replace per-inbox status events with a single aggregated unread-count publication via new `BeaUnreadCounter`.
- Add unit tests validating sum behavior and “unknown count => publish nothing” behavior.
