<summary><strong>What changed in this PR</strong></summary>

Addresses #2592 by adding collation compatibility handling to the backup manager’s database restore process.

**Changes:**
- Checks whether the target server supports `utf8mb4_0900_ai_ci` before attempting replacement.
- Adds a streaming SQL rewriter intended to preserve stored data, comments, and binary content.
- Adds 15 tests covering SQL parsing, byte preservation, incomplete dumps, and bounded memory use.
