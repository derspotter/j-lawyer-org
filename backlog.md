- [#2999](https://github.com/jlawyerorg/j-lawyer-org/issues/2999) Multiwindow fuer Sprachmemo-Funktion (client-ui, enhancement) - Follow-up of #2940, where notes became the non-modal AddNoteFrame registered via EditorsRegistry.registerFrame. M-sized Swing refactor, not headless-verifiable, so not F.
- [#2853](https://github.com/jlawyerorg/j-lawyer-org/issues/2853) Akte loeschen nur nach Passworteingabe / geschuetzte Akten (client-ui, enhancement) - Password re-entry vs protected flag is a product decision. A protected flag needs a new column (X). Password re-check must be enforced server-side to be meaningful. Maintainer: Issue by j-dimension, optional idea: mark cases as protected and prevent deletion.

Remaining item needs a decision: close it in favour of document multi-value tags, or add a dedicated category field (schema change, X). Maintainer: j-dimension updated the checklist on 2026-09-29 and left only the category item open.
- [#3101](https://github.com/jlawyerorg/j-lawyer-org/issues/3101) Erweiterte Sprecherbenennung bei Transkription (other, enhancement) - Two variants proposed (suggest names from case parties vs simple search/replace). The label format is defined by the external Ingo service. A small 'Sprecher umbenennen' dialog would be feasible once a variant is chosen.
- [#2934](https://github.com/jlawyerorg/j-lawyer-org/issues/2934) Weitere Ingo-Funktionen bei Notizen (other, enhancement) - Mirroring the e-mail Ingo menu in the note editor (button, AssistantInputAdapter, result insertion) is feasible but M-sized with .form changes. The concrete prompts (Antworten, Briefkopf, DeepL) are server-side Ingo configuration. Scope and placement undecided. Overlaps the context-menu idea in #3258.
- [#3319](https://github.com/jlawyerorg/j-lawyer-org/issues/3319) Falldaten (FDB) optional durchsuchbar machen (server, enhancement) - Maintainer explicitly says the implementation is unclear (switch in search UI, SQL join vs Lucene index). Performance of joining form entries also needs care. Maintainer: Implementation unclear, maybe a switch in the case search to include form data.
